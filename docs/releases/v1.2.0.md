# CLASH-AGENT v1.2.0 — Cloudflare WS automatic installation

Provide a Cloudflare-managed hostname and API Token to install the Cloudflare → nginx HTTPS → loopback sing-box VLESS-WS chain, with a private HTTPS Clash subscription and automatic renewal.

```bash
curl -fsSL https://github.com/nyaaorick/CLASH-AGENT/releases/download/v1.2.0/install.sh -o install.sh
sudo bash install.sh install --mode cloudflare-ws --domain node.example.com
```

Paste the API Token at the hidden prompt, or supply `--cf-token-file /root/cloudflare-token` with an owner-only regular file. Required token permissions: Zone Read, DNS Edit and Zone Settings Read on the owning zone. The zone must already allow WebSockets and use Full or Full (strict) SSL.

- Generates the UUID, WS path and private subscription path.
- Configures DNS-01 certificates, nginx, sing-box, origin address restrictions and maintenance timers.
- Preserves identity on repeat runs; supports explicit `--adopt-existing` for the documented single-node nginx/WS layout.
- Verifies certificate, subscription, WS, TCP/UDP and maintenance before reporting ready; adds scoped backup/rollback for failures.
- Keeps the existing default Reality + Vision installation.

TCP and application UDP travel inside WS/TCP; the ordinary Cloudflare CDN is not a native UDP relay.

Validation passed the full local suite, native Linux nginx/VLESS-WS TCP/UDP integration, official pinned acme.sh home-isolation checks and independent review. Real Cloudflare DNS writes and external CA issuance were not performed for this release. Existing servers are not automatically migrated by publication.

Downloads: `install.sh` and `SHA256SUMS`. Check the downloaded installer with `sha256sum -c SHA256SUMS` (macOS: `shasum -a 256 -c SHA256SUMS`).

See the [configuration and recovery guide](https://github.com/nyaaorick/CLASH-AGENT/blob/v1.2.0/scripts/CLASH-AGENT/documents/cloudflare-ws.md).
