# Upstream and modifications

CLASH-AGENT is based on [mack-a/v2ray-agent](https://github.com/mack-a/v2ray-agent), maintained as ordinary source files in this repository.

Patch 1.1.2 reads existing Fail2ban whitelists through the native public `get()` API, including legacy 0.10 adapters that do not expose `has_option()`, and accepts only the exact legacy response that the current management IP is already not banned.

- Upstream branch: `master`
- Imported commit: [`140b1659f1874aaefb1cdde412c6baefaf196198`](https://github.com/mack-a/v2ray-agent/commit/140b1659f1874aaefb1cdde412c6baefaf196198)
- Import and local modification date: 2026-11-06
- License: GNU Affero General Public License v3.0; original [LICENSE](LICENSE) retained.
- Original documentation: [README.upstream.md](README.upstream.md).

The original `install.sh` is preserved in [lib/upstream.sh](lib/upstream.sh), with its core downloads, key generation, Reality configuration, and service management. Local changes add a library-loading guard, shared Reality configuration and SNI-list helpers, and failure propagation fixes. The automatic workflow uses the existing service-registration function with deferred startup.

The development entry point [install.sh](install.sh) and small `lib/` modules implement unattended orchestration, BBR and swap setup, fail2ban SSH protection, and a Clash-specific subscription. Version 1.1.0 adds automatic fail2ban configuration and verification, with detected SSH ports, management-address protection when available, and preservation of unrelated jails and existing IP whitelists. The repository-root `install.sh` is generated by [build.sh](build.sh) as a standalone installer for direct download from GitHub. Upstream helper scripts, templates, and resources remain in `shell/`, `documents/`, and `fodder/`. The public distribution excludes the upstream `.github/workflows/create_release.yml` workflow because it deletes older releases and tags; the private source snapshot retains that file. Upstream code, resources, and license attribution are otherwise retained.

The CLASH-AGENT entry point prevents upstream self-update from replacing this fork. Other retained upstream features may still download upstream resources; check their download sources when changing those features.

Validation includes local isolated tests, syntax checks, configuration parsing, and a 2026-11-06 live deployment of version 1.1.2 on Debian 10. The public subscription, Reality-only HTTPS and exit-IP checks, and an SSH fail2ban ban/unban test passed. Host credentials and deployment records remain outside the public repository.
